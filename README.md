# NoDB-WebBase

A minimalist **PHP backend management system** for developers and small teams, featuring a front-end pretty URL routing framework with static/dynamic page hybrid rendering.

> **No Framework. No Dependencies. Pure PHP.**
>
> ⚠️ Some data is stored in `.log` files — ensure your web server denies direct browser access to `.log` files.
> ⚠️ MySQL interface is provided but no database client is bundled — extend as needed. Dynamic route interfaces with DB connection are reserved.

---

## Features

- **Pure PHP** — PHP 7.0+, zero dependencies, zero frameworks
- **Hybrid Storage** — Admin configs via files, business data via MySQL (PDO)
- **Single-User Login** — Dynamic token authentication per-minute
- **Multi-Account** — Multiple admin accounts with role-based permission levels
- **Pretty URL Routing** — Front-end `index.php` as single entry point, route-table-driven
- **Static/Dynamic Hybrid** — Manage static pages (about, terms) in admin panel; dynamic pages (tag, search, article) ready for database integration
- **Two-Part Templates** — `head + foot` template split for both admin and front-end
- **Draft-to-Production Routing** — Edit routes as drafts, validate, then activate
- **File Editor** — Edit PHP/config files directly from admin panel

## Quick Start

### 1. Deploy

Place the project in your web root directory (e.g., `/var/www/html/NoDB-WebBase`).

### 2. Web Server Configuration

**Nginx:**
```nginx
location / {
    try_files $uri $uri/ /index.php$is_args$args;
}

# Admin real path
location /adm/ {
    # no rewrite
}

# Protect .log files
location ~* \.log$ {
    deny all;
    return 404;
}
```

**Apache:** (`.htaccess`)
```apache
RewriteEngine On

# Front-end pretty URL routing
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php [QSA,L]

# Protect .log files
RewriteRule \.log$ - [F,NC]
```

### 3. Initialize

Visit `http://your-domain/setup.php` in a browser to start the setup wizard:

1. Choose the website language (sets HTML `lang` attribute on front-end; admin panel is always English)
2. Set the bound domain name
3. Create the first admin account (username + password)
4. Configure database (optional — skip for static-only mode)
5. Auto-generate table structure (when database is configured)

### 4. Login

Visit `http://your-domain/adm/login.php` to access the admin panel.

### 5. Activate Front-End Routing

After login, go to **Route Management** → select routes to activate → click "Activate". The home page (`/`) and static pages (`/about.html`, etc.) will then be accessible.

## Placeholder System

Parameters configured in **System Settings → Parameters** (`adm/sys.php?type=params`, stored in `inc/sys_config.php`) and **System Settings → UI Text** (`adm/sys.php?type=ui`, stored in `inc/sys_ui.php`) can be referenced anywhere using `{key_name}` syntax.

**Available in:**
- Front-end templates (`tpl/front_head.log`, `tpl/front_foot.log`)
- Dynamic Templates (`adm/pages.php?type=dynamic`, stored in `inc/site_dynamic.php`)
- Static Pages (`adm/pages.php?type=page`, stored in `inc/site_pages.php`)

**Examples:**

| Input | Rendered Output |
|-------|----------------|
| `<h1>{sys_site_name}</h1>` | `<h1>My Website</h1>` |
| `<title>{txt_web_home} - {sys_site_name}</title>` | `<title>Home - My Website</title>` |

# NoDB-WebBase

一个极简的 **PHP 后台管理系统**，面向开发者和小团队，支持前端伪静态路由与动静融合框架。

> **无框架、无依赖、纯原生 PHP**
>
> ⚠️ 部分数据存储在 `.log` 文件中——请确保服务器已拒绝浏览器直接访问 `.log` 文件。
> ⚠️ 仅提供 MySQL 接口，未捆绑数据库管理程序，可根据需要扩展。已预留连接数据库的动态路由备用接口。

---

## 功能特性

- **纯原生 PHP** — PHP 7.0+，零依赖、零框架
- **混合存储** — 管理员配置用文件存储，业务数据用 MySQL（PDO）
- **单用户登录** — 每分钟动态令牌认证
- **多账号管理** — 支持多管理员账号，基于角色的权限级别
- **伪静态路由** — 前端 `index.php` 统一入口，路由表驱动
- **动静融合** — 静态页（关于、条款）后台管理；动态页（标签、搜索、文章）预留数据库接入
- **两段式模板** — 后台和前端均采用 head + foot 模板分离
- **草稿生效机制** — 路由草稿编辑→校验→生效，安全可控
- **文件编辑器** — 后台直接编辑 PHP/配置文件

## 快速开始

### 1. 部署

将项目放入 Web 根目录（如 `/var/www/html/NoDB-WebBase`）。

### 2. Web 服务器配置

**Nginx：**
```nginx
location / {
    try_files $uri $uri/ /index.php$is_args$args;
}

# Admin real path
location /adm/ {
    # no rewrite
}

# Protect .log files
location ~* \.log$ {
    deny all;
    return 404;
}
```

**Apache：（`.htaccess`）**
```apache
RewriteEngine On

# 前端伪静态路由
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php [QSA,L]

# 阻止直接访问 .log 文件
RewriteRule \.log$ - [F,NC]
```

### 3. 系统初始化

浏览器访问 `http://your-domain/setup.php` 进入安装向导：

1. 选择网站语言（仅设置前端 HTML `lang` 属性；后台始终为英文）
2. 设置绑定域名
3. 创建第一个管理员账号（用户名 + 密码）
4. 配置数据库（可选——跳过则仅静态模式）
5. 自动建表（配置数据库后可选）

### 4. 登录后台

访问 `http://your-domain/adm/login.php` 进入后台管理。

### 5. 激活前端路由

登录后进入 **路由管理** → 勾选需要激活的路由 → 点击「确认生效」。首页（`/`）和静态页（`/about.html` 等）即可访问。
