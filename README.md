# NoDB-WebBase

A minimalist **PHP flat-file CMS and admin panel** with pretty URL routing, 3 universal page types, code block isolation, IP/UA security, AJAX popups, and optional MySQL support.

> **No Framework. No Dependencies. Pure PHP.**
>
> ⚠️ Ensure your web server denies direct browser access to `.log` files.
> ⚠️ MySQL interface is provided but no database client is bundled.

---

## Features

- **Zero-database core** — Site config, nav, links, countries, agents, sitemaps all stored as flat files. MySQL optional for business data.
- **One-click setup** — `setup.php` wizard: set domain, create admin account. Ready in seconds.
- **3 universal page types** — `page` (static HTML), `code` (PHP logic), `api` (JSON endpoint)
- **Auto-compiled URL patterns** — Enter `/tag/{abc}` → system generates regex `~^/tag/([^/]+)$~` automatically
- **Code block isolation** — PHP logic stored as standalone `tpl/code_{key}.log` files, edited via File Editor
- **Country Manager** — Full CRUD for country database, generates `{site:country_en}` / `{site:country_cn}` HTML dropdowns
- **IP / User-Agent Security** — 4-level black/whitelist, blocks malicious bots and IPs before page render
- **AJAX Popup System** — Reusable popup overlay: add `tpl/ajax_{type}.log` content, invoke via `openshow('type')`
- **Sitemap Auto-Generation** — `/sitemap.xml` generated from 3 merge layers (manual, tag, info)
- **Friend Links Manager** — Add/edit/delete links, rendered via `{site:links}` placeholder
- **Front-end Navigation** — Manage nav items, `{site:menu}` with active state highlighting
- **Extended Placeholder System** — `{site:menu}`, `{site:router}`, `{site:path}`, `{site:links}`, `{site:country_en/cn}`, `{code:xxx}`, `{sys_xxx}`, `{ui_xxx}`
- **File Editor** — Online editing of `pics/`, `tpl/`, `data/` files with extension whitelist
- **Image Upload** — Supports jpg, jpeg, png, gif, webp, bmp, svg, ico
- **Multi-account** — Role-based permission levels (20 Super Admin → 10 Observer)
- **MySQL Management** — Configure DB, test connection, execute SQL, table-level permission whitelist, all from admin panel

## Quick Start

### 1. Deploy

Place the project in your web root directory.

### 2. Web Server Configuration (Pretty URL / Rewrite Rules)

**Nginx:**
```nginx
location / {
    try_files $uri $uri/ /index.php$is_args$args;
}
location /adm/ { }
location ~* \.log$ { deny all; return 404; }
```

**Apache (`.htaccess`):**
```apache
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php [QSA,L]
RewriteRule \.log$ - [F,NC]
```

### 3. Initialize

Visit `http://your-domain/setup.php`:

1. Set the bound domain name (do NOT include `http://` or `www`)
2. Admin password auto-generated as `username + 6-digit date` (e.g. `admin260530`)
3. Database can be configured later via admin panel Settings → SQL

### 4. Login

Visit `http://your-domain/adm/login.php`

### 5. Activate Front-End Pages

Login → **Pages** tab → set route status to Active(2) → click Save.

| Type | Code Block | Title/Desc/Content | Template | Use Case |
|------|-----------|-------------------|----------|----------|

### URL Pattern Compilation

| Input | Compiled Match | Vars |
|-------|---------------|------|
| `/about.html` | `/about.html` | `[]` |
| `/tag/{abc}` | `~^/tag/([^/]+)$~` | `['abc']` |
| `/article/{fn}.html` | `~^/article/([^/]+)\.html$~` | `['fn']` |
| `/news/{abc}/{1}.html` | `~^/news/([^/]+)/(\d+)\.html$~` | `['abc', '1']` |

- `{letter}` → `([^/]+)`, `{digit}` → `(\d+)`
- Special regex chars (`.`) auto-escaped

### Route Status

| Status | Meaning | Compiled | Accessible |
|--------|---------|----------|------------|
| 2 Active | Enabled | Yes | Yes |
| 2 Paused | Suspended | No | No |
| 0 Delete | Marked for deletion | No | No |

Active route fields are read-only — set to Paused first to edit.

## IP / User-Agent Security

The security system (`data/site_agent.log`) supports 4 rule levels:

| Level | Field | Match Against | Behavior |
|-------|-------|---------------|----------|
| 1 | IP | Client IP prefix | **503 block** — Blacklist |
| 2 | User-Agent | UA substring | **503 block** — Blacklist |
| 3 | IP | Client IP prefix | **Set `$isWhitelisted=true`, pass** — Whitelist |
| 4 | User-Agent | UA substring | **Set `$isWhitelisted=true`, pass** — Whitelist |

**Configuration params** (`sys_config.php` → Settings → Params):
- `sys_site_agent_block` — 0=off, 1=block matching agents
- `sys_site_agent_log` — 0=no logging, 1=log blocked requests

## AJAX Popup System

Add popup content files as `tpl/ajax_{type}.log` and call them from front-end:

```javascript
openshow('terms')   // Loads tpl/ajax_terms.log
openshow('email')   // Loads tpl/ajax_email.log
```

The built-in handler `tpl/code_ajax.log` processes requests to `/ajax?type=...`, applies `{sys_xxx}` / `{ui_xxx}` placeholders, and returns JSON.

Default popups included: Terms of Service (`ajax_terms.log`), Contact Email (`ajax_email.log`).

## Sitemap Generation

`/sitemap.xml` is generated from 3 merge layers:

| Layer | File | Description |
|-------|------|-------------|
| Manual | `data/sitemap_manual.log` | Manually curated entries (url|lastmod|freq|priority) |
| Tag | `data/sitemap_tag.log` | Tag-based entries (auto-generated) |
| Info | `data/sitemap_info.log` | Info-based entries (auto-generated) |

Edit these files via **Settings → File Editor** to update your sitemap.

## SQL Management

The **SQL** tab (`sys.php?type=sql`) provides:

- **Database Configuration** — Set MySQL host/name/user/password, test connection
- **SQL Executor** — Run single SQL statements; SELECT results rendered as HTML table
- **Protected Table Whitelist** — `data/sql_protected.log` stores table-level permissions:

| Level | Permission |
|-------|-----------|
| 10 | Full access (schema + data, including DROP) |
| 9 | Alter fields only |
| 8 | CRUD row data |
| 5 | Read only |

CREATE TABLE is always allowed and auto-adds the new table to the whitelist at level 8.

# NoDB-WebBase

极简的 **PHP 纯文件内容管理系统 + 后台管理面板**，支持伪静态路由、3 种通用页面类型、代码块独立存储、IP/UA 安全拦截、AJAX 弹窗和可选 MySQL 支持。

> **无框架、无依赖、纯原生 PHP**
>
> ⚠️ 确保服务器已拒绝浏览器直接访问 `.log` 文件。
> ⚠️ 系统提供 MySQL 接口，但未捆绑数据库客户端。

---

## 功能特性

- **零数据库核心** — 站点配置、导航、友情链接、国家数据、IP 规则、站点地图均以纯文件存储。MySQL 仅用于业务数据（可选）。
- **一键安装** — `setup.php` 安装向导：绑定域名、创建管理员账号。秒级完成。
- **3 种通用页面类型** — `page`（纯静态 HTML）、`code`（PHP 逻辑）、`api`（JSON 接口）
- **URL Pattern 自动编译** — 输入 `/tag/{abc}` → 系统自动生成正则 `~^/tag/([^/]+)$~`
- **代码块独立存储** — PHP 逻辑存为 `tpl/code_{key}.log`，通过 File Editor 在线编辑
- **国家数据库管理** — 完整 CRUD，一键生成 `{site:country_en}` / `{site:country_cn}` HTML 下拉菜单
- **IP / User-Agent 安全系统** — 4 级黑白名单，页面渲染前拦截恶意爬虫和 IP
- **AJAX 弹窗系统** — 通用弹窗框架：添加 `tpl/ajax_{type}.log` 内容，前端 `openshow('type')` 调用
- **站点地图自动生成** — `/sitemap.xml` 从 3 层数据（手动/标签/信息）合并生成
- **友情链接管理** — 添加/编辑/删除，通过 `{site:links}` 占位符渲染
- **前端导航管理** — 管理导航项，`{site:menu}` 渲染带活跃状态高亮
- **扩展占位符系统** — `{site:menu}`、`{site:router}`、`{site:path}`、`{site:links}`、`{site:country_en/cn}`、`{code:xxx}`、`{sys_xxx}`、`{ui_xxx}`
- **文件在线编辑器** — 在线编辑 `pics/`、`tpl/`、`data/` 文件，带扩展名白名单
- **图片上传** — 支持 jpg/jpeg/png/gif/webp/bmp/svg/ico
- **多账号管理** — 基于角色的权限等级（20 超级管理员 → 10 观察员）
- **MySQL 管理** — 后台配置数据库、测试连接、执行 SQL、表级权限白名单

### 3 种页面类型

| 类型 | 代码块 | 标题/描述/内容 | 模板 | 用途 |
|------|--------|--------------|------|------|
| `page` | ❌ | ✅ | ✅ 完整 HTML | 静态页面（关于、条款） |
| `code` | ✅ | ✅ | ✅ 完整 HTML | 带 PHP 逻辑的动态页面 |
| `api` | ✅ | ❌ | ❌ 无模板 | JSON/纯文本响应 |

### URL Pattern 自动编译

| 输入 | 编译结果 | 变量 |
|------|---------|------|
| `/about.html` | `/about.html` | 无 |
| `/tag/{abc}` | `~^/tag/([^/]+)$~` | `abc` |
| `/article/{fn}.html` | `~^/article/([^/]+)\.html$~` | `fn` |
| `/news/{abc}/{1}.html` | `~^/news/([^/]+)/(\d+)\.html$~` | `abc, 1` |

- `{字母}` → `[^/]+`，`{数字}` → `\d+`，`.` 自动转义

### 路由状态

| 状态 | 含义 | 编译到路由表 | 可访问 |
|------|------|------------|--------|
| 2 Active | 启用 | ✅ | ✅ |
| 1 Paused | 暂停 | ❌ | ❌ |
| 0 Delete | 删除 | ❌ | ❌ |

Active 状态下 Pattern 和 Key 只读，需先改为 Paused 才能编辑。

## IP / User-Agent 安全系统

安全系统（`data/site_agent.log`）支持 4 级规则：

| 级别 | 匹配字段 | 匹配对象 | 命中行为 |
|------|---------|---------|---------|
| 1 | IP | 客户端 IP 前缀 | **503 拦截** — 黑名单 |
| 2 | User-Agent | UA 子串 | **503 拦截** — 黑名单 |
| 3 | IP | 客户端 IP 前缀 | **设 `$isWhitelisted=true`，放行** — 白名单 |
| 4 | User-Agent | UA 子串 | **设 `$isWhitelisted=true`，放行** — 白名单 |

**配置参数**（`sys_config.php` → 设置 → 参数）：
- `sys_site_agent_block` — 0=关闭，1=拦截匹配的 agent
- `sys_site_agent_log` — 0=不记录，1=记录被拦截请求

## AJAX 弹窗系统

添加弹窗内容文件 `tpl/ajax_{type}.log`，通过前端调用：

```javascript
openshow('terms')   // 加载 tpl/ajax_terms.log
openshow('email')   // 加载 tpl/ajax_email.log
```

内置处理器 `tpl/code_ajax.log` 处理 `/ajax?type=...` 的请求，自动应用 `{sys_xxx}` / `{ui_xxx}` 占位符，返回 JSON。

默认包含两个弹窗：服务条款（`ajax_terms.log`）、联系邮箱（`ajax_email.log`）。

## SQL 管理

**SQL** 标签页（`sys.php?type=sql`）提供：

- **数据库配置** — 设置 MySQL 主机/库名/用户/密码，测试连接
- **SQL 执行器** — 执行单条 SQL，SELECT 结果渲染为 HTML 表格
- **受保护表白名单** — `data/sql_protected.log` 存储表级权限：

| 级别 | 权限 |
|------|------|
| 10 | 完全访问（包括 DROP） |
| 9 | 仅改字段 |
| 8 | 增删改数据 |
| 5 | 仅查询 |

CREATE TABLE 始终放行，执行后自动加入白名单（级别 8）。
