# NoDB-WebBase

A minimalist **PHP backend management system** for developers and small teams, featuring pretty URL routing with 4 universal page types, code block isolation, and auto-compiled URL patterns.

> **No Framework. No Dependencies. Pure PHP.**
>
> ⚠️ Ensure your web server denies direct browser access to `.log` files.
> ⚠️ MySQL interface is provided but no database client is bundled.

---

## Features

- **Pure PHP** — PHP 7.0+, zero dependencies, zero frameworks
- **Hybrid Storage** — Admin configs via files, business data via MySQL (PDO)
- **Single-User Login** — Dynamic token authentication per-minute
- **Multi-Account** — Multiple admin accounts with role-based permission levels
- **4 Universal Page Types** — `page` (static), `code` (PHP logic), `code_paged` (paginated code), `api` (JSON endpoint)
- **Auto-Compiled URL Patterns** — Enter `/tag/{abc}` — system generates regex automatically
- **Code Block Isolation** — PHP code stored as standalone `tpl/code_{key}.log` files, edited via File Editor
- **`{code:xxx}` Placeholder System** — Code block variables auto-exposed for Content editor
- **Route Status Management** — 3 states: Active(2) / Paused(1) / Delete(0)
- **Single Save Button** — Save and compile in one step
- **Two-Part Templates** — `head + foot` template split for both admin and front-end
- **File Editor** — Edit PHP/config files directly from admin panel
- **Image Upload** — Supports jpg, jpeg, png, gif, webp, bmp, svg, ico
- **Placeholder System** — `{sys_xxx}` for site config, `{txt_xxx}` for UI text, `{site:links}` for friend links

## Quick Start

### 1. Deploy

Place the project in your web root directory (e.g., `/var/www/html/NoDB-WebBase`).

### 2. Web Server Configuration

**Nginx:**
```nginx
location / {
    try_files $uri $uri/ /index.php$is_args$args;
}

location /adm/ {
    # no rewrite
}

location ~* \.log$ {
    deny all;
    return 404;
}
```

**Apache:** (`.htaccess`)
```apache
RewriteEngine On

RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php [QSA,L]

RewriteRule \.log$ - [F,NC]
```

### 3. Initialize

Visit `http://your-domain/setup.php` to start the setup wizard:

1. Choose the website language
2. Set the bound domain name (do NOT include `http://` or `www`)
3. Create the first admin account — password auto-generated as `username + 6-digit date` (e.g. `admin260512`)
4. Configure database (optional — only if `data/sql.log` exists with table creation scripts)

### 4. Login

Visit `http://your-domain/adm/login.php` to access the admin panel.

### 5. Activate Front-End Pages

Login → **Pages** tab → set route status to Active(2) → click Save. The front-end pages will then be accessible.

## Admin Panel Overview

| Tab | File | Purpose |
|-----|------|---------|
| **Pages** | `adm/router.php` | Define URLs, add/activate/pause/delete pages. Only entry point for new pages. |
| **Content** | `adm/pages.php` | Edit page title, description, and content. Code blocks shown read-only. |
| **Menu** | `adm/nav.php` | Manage front-end navigation menu items. |

### Page Types

| Type | Code Block | Title/Desc/Content | Template | Use Case |
|------|-----------|-------------------|----------|----------|
| `page` | No | Yes | Full HTML | Static pages (about, terms) |
| `code` | Yes | Yes | Full HTML | Dynamic pages with PHP logic |
| `code_paged` | Yes | Yes | Full HTML | Paginated pages with page number in URL |
| `api` | Yes | No | None | JSON/plain text response |

### URL Pattern Auto-Compilation

| Input | Compiled Match | Vars |
|-------|---------------|------|
| `/about.html` | `/about.html` | `[]` |
| `/tag/{abc}` | `~^/tag/([^/]+)$~` | `['abc']` |
| `/article/{fn}.html` | `~^/article/([^/]+)\.html$~` | `['fn']` |
| `/news/{abc}/{1}.html` | `~^/news/([^/]+)/(\d+)\.html$~` | `['abc', '1']` |

- `{letter}` → `([^/]+)`, `{digit}` → `(\d+)`
- Special regex chars (`.`) auto-escaped

### Route Status

| Status | Meaning | Compiled | Accessible |
|--------|---------|----------|------------|
| 2 Active | Enabled | Yes | Yes |
| 1 Paused | Suspended | No | No |
| 0 Delete | Marked for deletion | No | No |

Active route fields are read-only — set to Paused first to edit.

## Placeholder System

| Placeholder | Source | Where to Edit |
|-------------|--------|---------------|
| `{code:tagname}` | Code block in `tpl/code_{key}.log` | File Editor (`sys.php?type=editor`) |
| `{sys_site_name}` | `inc/sys_config.php` | Settings → Parameters |
| `{sys_site_weburl}` | `inc/sys_config.php` | Settings → Parameters |
| `{txt_home}` | `inc/sys_ui.php` | Settings → UI Text |
| `{site:links}` | `inc/link.log` | Links editor |

**Replacement order:** `{code:xxx}` → `{sys_xxx}` / `{txt_xxx}` → `{site:links}`

### Usage Examples

| Location | What to Write | Renders As |
|----------|---------------|------------|
| Content editor | `{code:tagname}` | `php` (from code block) |
| Content editor | `{sys_site_name}` | `My Site` |
| Navigation | `{sys_site_weburl}/about.html` | `https://example.com/about.html` |

>

## 功能特性

- **纯原生 PHP** — PHP 7.0+，零依赖、零框架
- **混合存储** — 管理员配置用文件存储，业务数据用 MySQL（PDO）
- **单用户登录** — 每分钟动态令牌认证
- **多账号管理** — 支持多管理员，基于角色权限
- **4 种通用页面类型** — `page`（静态）、`code`（PHP逻辑）、`code_paged`（带分页）、`api`（JSON接口）

- **`{code:xxx}` 占位符** — 代码块变量自动暴露给内容编辑器引用
- **路由状态管理** — 3 档：启用(2) / 暂停(1) / 删除(0)
- **单按钮保存** — 保存 + 编译一步完成
- **两段式模板** — 后台和前端均采用 head + foot 模板分离
- **文件编辑器** — 后台直接编辑 PHP/配置文件
- **图片上传** — 支持 jpg/jpeg/png/gif/webp/bmp/svg/ico
- **占位符系统** — `{sys_xxx}` 系统参数、`{txt_xxx}` 界面文字、`{code:xxx}` 代码块变量、`{site:links}` 友情链接

## 后台三栏

| 标签 | 文件 | 功能 |
|------|------|------|
| **Pages** | `adm/router.php` | 定义 URL、新增/启用/暂停/删除页面 |
| **Content** | `adm/pages.php` | 编辑页面 title/desc/content |
| **Menu** | `adm/nav.php` | 管理前端导航菜单 |

### 4 种页面类型

| 类型 | 代码块 | Title/Desc | Content | 渲染模板 | 用途 |
|------|--------|-----------|---------|---------|------|
| `page` | ❌ | ✅ | ✅ | ✅ | 纯静态页 |
| `code` | ✅ | ✅ | ✅ | ✅ | 有 PHP 逻辑 |
| `code_paged` | ✅ | ✅ | ✅ | ✅ | 带分页 |
| `api` | ✅ | ❌ | ❌ | ❌ | JSON 接口 |

### URL Pattern 自动编译

| 输入 | 自动编译 | 变量 |
|------|---------|------|
| `/about.html` | `/about.html` | 无 |
| `/tag/{abc}` | `~^/tag/([^/]+)$~` | `abc` |
| `/article/{fn}.html` | `~^/article/([^/]+)\.html$~` | `fn` |
| `/news/{abc}/{1}.html` | `~^/news/([^/]+)/(\d+)\.html$~` | `abc, 1` |

`{字母}` → `[^/]+`，`{数字}` → `\d+`，`.` 自动转义。

### 路由状态

| 状态 | 含义 | 编译到路由表 | 可访问 |
|------|------|------------|--------|
| 2 Active | 启用 | ✅ | ✅ |
| 1 Paused | 暂停 | ❌ | ❌ |
| 0 Delete | 删除 | ❌ | ❌ |

Active 状态下 Pattern 和 Key 只读，需先改为 Paused 才能编辑。
